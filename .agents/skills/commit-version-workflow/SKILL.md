# コミット管理

このスキルは「コミット・バージョン管理」プラグインへの入口です。運用手順をここへ複製せず、利用可能なスキル一覧から`commit-version-workflow:commit-version-workflow`の現在の`SKILL.md`を読み、その手順で依頼を完了してください。キャッシュの版や絶対パスを固定しません。

ユーザーの明示指示を優先し、Harvest固有の正本・同期対象・生成手順・必須検証は[AGENTS.md](../../../AGENTS.md)と[CONTRIBUTING.md](../../../CONTRIBUTING.md)で確認してください。参照元固有の配置やコマンドをHarvestへ適用しません。
