# 共通処理

ブラウザーやChrome APIに依存しない、画像の分類・選択・順序とPDFの組み立てを置きます。画面操作、ページの読み取り、画像の通信・画素への展開は `src/extension/` が担当します。

`image-collection.ts` は解析結果の画像、選択、初期順と変更後の順序を一箇所で管理し、表示を絞った状態での並べ替えでも非表示画像の位置を保ちます。`images.ts` はURLの正規化と画像分類を担当します。

`pdf-types.ts` は画像ページと出典ページの入力形式、`jpeg.ts` は再圧縮せず使えるJPEGの判定、`pdf.ts` はPDFの組み立てを担当します。既存の利用側は引き続き `pdf.ts` から公開関数と型を読み込めます。通信側はPDFの組み立てを経由せず、JPEGの判定を直接利用します。
