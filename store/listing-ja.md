# Chrome ウェブストア掲載文（日本語）

## 基本情報

- 名前: Harvest
- 概要: Webページから画像や動画を集め、保存したい項目と順番を選んで端末に保存できます。
- 言語: 日本語
- 主なカテゴリの候補: 仕事効率化
- 価格の候補: 無料

## 詳細説明

Harvestは、Webページから画像や動画を集め、必要な項目を選んで端末へ保存するGoogle Chrome™向け拡張機能です。画像と動画の保存方法は、それぞれ選べます。拡張機能のアイコンを押すとサイドパネルが開き、見ているページを離れずに作業できます。

- 表示中のページを解析するか、URLを入力・ドラッグして解析できます。一般ページではChromeが読み取りを許可する埋め込みページも対象です。収集モードではページ内のリンクをクリックして連続解析できます。
- まとまりごとに表示を絞り込み、保存対象と順番を変更できます。表示の絞り込みは保存対象の選択を変えません。漫画本文とみなせるまとまりがある場合は、その画像を初めに選択します。
- 静止画像は元の大きさのページを持つPDFにまとめられます。画像の推奨形式は、選択中の静止画像が一つのシリーズやセットに属する場合はPDF、それ以外は元形式を使います。PDFの末尾には任意で出典ページを追加できます。
- 動く画像は元形式で保持するか、画像変換を選んだ場合はアニメーションとして保存します。対応する動画から音声だけを保存することもできます。音声は再圧縮のため音質が変わる場合があり、無音声や非対応の音声は理由を表示して停止します。
- 出力が一つなら直接保存し、複数の画像や、画像と動画・音声を組み合わせた出力は一つの圧縮ファイルにまとめます。動画だけを選んで推奨形式で保存する場合や、動画の変換・音声の取り出しを行う場合は、Chromeで完了を確認しながら個別に保存します。動画を元形式で保存する場合は、複数の出力を一つの圧縮ファイルにまとめます。
- 全項目の準備後に保存を始めます。取得・変換に失敗した項目や個別保存の未完了項目だけを再試行できます。中止しても、既に保存を完了したファイルは端末に残ります。

ページの読み取り、メディアの変換、保存するファイルの作成はブラウザー内で行います。実行コードは拡張機能に同梱し、外部サーバーから取得しません。開発者のサーバーへページやメディアを送信しません。収集結果と選択した保存形式はパネル内のメモリだけで扱い、パネルを閉じると破棄します。パネルを開くたびに画像・動画とも推奨形式で始まります。出典ページのオン・オフだけをブラウザー内に保持します。Chromeで読めないページや取得が許可されないメディア、容量・時間・対応形式の上限を超える項目は保存できません。

Google Chrome は Google LLC の商標です。この商標の使用は Google Permissions に従います。

## プライバシー欄に入力する文面

### 単一の目的

利用者が指定したWebページから画像・GIF・動画を集め、選択した項目をPDF、元形式または変換した画像・動画、動画から取り出したMP3音声として端末に保存すること。出力数と種類に応じて直接・個別保存またはZIPにまとめる。

### 権限の理由

| 権限 | 入力する理由 |
| --- | --- |
| tabs | 解析ボタンを押したときに現在のページの名前とURLを読み取り、指定された一般ページを最小化した解析用ウィンドウで開き、解析後に閉じるため。YouTubeでは開いている対象ページまたは既存ページ内の非表示フレームを使う。 |
| scripting | 利用者が解析を開始したページと読み取り可能な埋め込み文書のメディアURL・タイトル・動画の再生情報を読み取り、収集モードでリンクのクリックを読み取るため。 |
| sidePanel | ツールバーのアイコンから、閲覧中のページの横に項目の選択と保存の画面を表示するため。 |
| downloads | Harvestが開始した個別保存のIDと完了・中断状態だけを確認し、中止・未完了分の再試行を行うため。他のダウンロードや履歴全体は読み取らず、既存ファイルや保存履歴を削除しない。 |
| HTTP/HTTPSのサイトへのアクセス | 利用者が指定したページと読み取り可能な埋め込み文書を解析し、別の配信元も含む対象メディアを取得して端末に保存するため。Xではページ開始時からX自身が受信したブックマーク一覧の必要な情報を当該ページ内で一時保持し、解析時に利用する。 |

### 遠隔コード

「使用しない」。JavaScriptとJXL変換用のWebAssemblyを含む実行コードはすべて拡張機能のZIPに含まれ、外部のコードを読み込まない。画像・動画・音声の変換サービスは使用しない。

### 利用者データ

現在または指定したページと読み取り可能な埋め込み文書のタイトル・URL・メディアURL、取得した画像・GIF・動画・音声データを、表示・変換・ファイル作成のためブラウザー内で処理する。収集モードのリンクURLと、Xの既存のブックマーク応答から得る投稿ID・メディアURLも必要な処理中だけ扱う。配信元への取得通信は行うが、開発者のサーバーへ送信しない。

収集結果と保存形式の選択はパネル内のメモリだけに保持し、パネルを閉じると破棄する。出典ページのオン・オフだけをブラウザー内へ保存し、収集結果を設定に保存しない。X側の一時情報は当該ページの終了や一覧切替などで破棄する。Harvestが開始した個別保存の完了・中断状態だけを確認し、他のダウンロード履歴は読み取らない。保存済みのPDF・画像・動画・MP3・ZIPは利用者の端末に残る。画面のデータ区分はこれらの処理とプライバシーポリシーに照らして選択する。

### プライバシーポリシーURL

`https://github.com/akihisa-dev/Harvest/blob/main/docs/privacy-policy.md` を入力する。提出前に、ログインせず閲覧できることを確認する。

## 審査担当者向け操作手順

1. 画像・GIF・MP4/WebM動画を掲載した、ログイン不要のHTTP/HTTPSページをブラウザーで開く。音声保存の確認には音声付きの動画を使う。
2. Harvestのアイコンを押し、「解析」を押す。URLを入力して「解析」を押すか、URLをドラッグして開始することもできる。
3. 保存対象を選び、画像と動画の形式欄を独立して操作する。画像は元形式・推奨形式・PDF・JPG・PNG・JXL、動画は元形式・推奨形式・MP4・音声（MP3）を確認する。種類がない場合は対応する形式欄が隠れる。
4. 「保存」を押す。出力が一つなら直接、複数画像や混在出力ならZIP、動画だけの推奨・MP4・MP3なら個別にダウンロードする。個別保存はChromeでの保存完了後に成功表示となる。失敗時は未完了分だけを再試行できる。
5. PDFとなる選択で出典ページをオンにし、末尾の出典を確認する。パネルを閉じて開き直すと、画像・動画の形式は推奨へ戻り、出典ページのオン・オフは保持される。

この確認に特定サイトのログインや実際の認証情報は必要ない。
