# Chrome ウェブストア掲載文（日本語）

## 基本情報

- 名前: Harvest
- 概要: Webページの画像をサイドパネルで集め、選択してPDFに保存します。
- 言語: 日本語
- 主なカテゴリの候補: 仕事効率化
- 価格の候補: 無料

## 詳細説明

Harvestは、Webページの画像を集め、必要な画像を選んで1つのPDFに保存するChrome拡張機能です。拡張機能のアイコンを押すとサイドパネルが開き、見ているページを離れずに作業できます。

- 表示中のページを解析するか、URLを入力・ドラッグして解析できます。
- 画像一覧につながる同じサイトのリンクも調べられます。
- 画像のまとまりで表示を絞り込み、1枚ずつ選べます。表示の絞り込みはPDFに入れる画像の選択を変えません。漫画本文とみなせるまとまりがある場合は、その画像を初めに選択します。
- 画像の順番とPDFに埋め込む画像の画質を調整できます。
- 画像を1枚ずつ元の大きさのPDFページにして、端末へ保存します。取得に失敗した画像は飛ばし、件数を表示します。

ページの読み取りとPDF作成はブラウザー内で行います。開発者のサーバーへページや画像を送信しません。収集結果は保存せず、サイドパネルを閉じると破棄します。Chromeで開けないページや、画像の取得が許可されていないサイトでは利用できない場合があります。

## プライバシー欄に入力する文面

### 単一の目的

利用者が指定したWebページから画像を集め、選択した画像をPDFとして端末に保存すること。

### 権限の理由

| 権限 | 入力する理由 |
| --- | --- |
| tabs | 解析ボタンを押したときに現在表示しているページの名前とURLを読み取り、入力されたURLや画像一覧のリンク先を一時的なタブで開いて、調査後に閉じるため。 |
| scripting | 利用者が解析を開始したページの画像URL、ページタイトル、画像一覧へのリンクを読み取るため。 |
| sidePanel | ツールバーのアイコンから、閲覧中のページの横に画像選択とPDF保存の画面を表示するため。 |
| HTTP/HTTPSのサイトへのアクセス | 利用者が任意のWebページを指定でき、画像が元ページとは別の配信元にある場合も読み取ってPDFにするため。利用者が解析を始めたページと画像にだけアクセスする。 |

### 遠隔コード

「使用しない」。実行するJavaScriptはすべて拡張機能のZIPに含まれ、外部のコードを読み込まない。

### 利用者データ

解析ボタンを押したときの現在のページのタイトルとURL、指定したページのタイトル・画像URL・リンク、取得した画像データを、表示とPDF作成のためブラウザー内で処理する。URLを入力またはドロップした場合は、入力されたURLを解析する。開発者のサーバーへ送信せず、サイドパネルを閉じると破棄する。保存したPDFは利用者の端末に残る。画面のチェック項目では「Webサイトのコンテンツ」「Web閲覧に関する情報」など、これらに該当する区分を正確に選択する。

### プライバシーポリシーURL

`https://github.com/akihisa-dev/Harvest/blob/main/docs/privacy-policy.md` を入力する。提出前に、ログインせず閲覧できることを確認する。

## 審査担当者向け操作手順

1. 画像を掲載した、ログイン不要のHTTP/HTTPSページをChromeで開く。
2. Harvestのアイコンを押し、「解析」を押す。URLを使う場合は入力して「解析」を押すか、URLをドラッグして開始する。
3. 画像を選び、「選択した画像をPDFにする」を押す。

特定サイトのログインや認証情報は必要ない。
